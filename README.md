# Hanzala Saqib Portfolio

This is a modern portfolio website built with React, Vite, and Tailwind CSS.

## Features

- Modern and responsive design
- Built with React and TypeScript
- Styled with Tailwind CSS and Shadcn UI
- Client-side routing with Wouter

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- pnpm (recommended) or npm/yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Hanzala-Saqib/portfolio.git
   ```

2. Install dependencies:
   ```bash
   pnpm install
   ```

3. Start the development server:
   ```bash
   pnpm run dev
   ```

### Building for Production

To build the project for production:

```bash
pnpm run build
```

The built files will be in the `dist/public` directory.
